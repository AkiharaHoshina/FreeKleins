# 06 · 逆向工具链

全部在 `D:\KleinsPatch\_re\`。这些是自建工具，不是现成软件的配置。

## 6.1 核心工具

### ★ `ljbc.py` —— LuaJIT 2.1 字节码反汇编器（纯 Python）

**这套破拆里最重要的一个工具。**

- 纯 Python，**不需要任何 LuaJIT 运行时**，直接读文件
- 解锁了全部 **672 个 Lua 文件**的逻辑（它们是剥离调试信息的 LuaJIT 字节码，本来没法读）
- 用法：
  ```
  python ljbc.py <文件.lua>                 # 反汇编整个文件
  python ljbc.py <文件.lua> --proto 24      # 只看第 24 号子函数
  python ljbc.py <文件.lua> --find 子串     # 按字符串常量定位子函数
  ```

### ★ `validate.py` —— 反汇编器校准

用 lupa 自带的 LuaJIT 把**已知 Lua 源码**编译成剥离调试信息的字节码，
再用 `ljbc.py` 反汇编，**并排打印源码与反汇编**。

存在的意义：确认 `ljbc.py` 对寄存器/调用/**比较跳转**的语义解读是否正确。
**正是靠它推翻了之前那个错误的分支语义结论**（见 [07](07_踩坑与结论.md)）。

### `disasm.py` / `raw.py` —— IL2CPP 层

- `disasm.py`：基于 **capstone** 的定向反汇编 + **字符串交叉引用**
  （靠 `script.json` 的 `ScriptString` 槽位）
- `raw.py`：把指定 RVA 区间的机器码原样反汇编，看控制流和立即数
- 配套：`addr.py` 打印 `ScriptMethod` / `ScriptString` 的地址范围

### `xref.py` —— 字符串交叉引用

用 Il2CppDumper 的 `script.json` 找出某个方法地址区间内引用的所有字符串字面量。
**不需要反汇编**——`ScriptString` 直接给出「代码地址 → 字面量」的映射。

```
python xref.py <方法名子串> [更多子串...]
```

### `pbdesc.py` —— 从字节码重建 protobuf 描述符

从 luapb 生成的 `pb.lua`（LuaJIT 字节码）里重建 protobuf 描述符。
它模拟字节码：`GGET/GSET` 取全局、`KSTR/KSHORT/KPRI/KNUM` 读常量、
`TGETS+CALL` 识别 `Descriptor/FieldDescriptor` 构造、`TSETS/TSETB` 设属性。
输出：**消息名 → 字段表**。

业务服的 protobuf 字段定义就是这么来的（并与 `dump.cs` 做了交叉验证）。

### `tcpcap.py` —— TCP 抓包器

监听 10301，打印每条连接收到的**原始字节（hex + ascii）**，**不回应**
（让客户端超时/报错），用于观察登录握手的前几个包。

### `probe_server.py` —— HTTP 探针

监听 127.0.0.1:10300，记录客户端发来的每一个请求。
用来验证：客户端会不会读它自带的 Hosts 文件、能不能接受 `http://` 明文。

## 6.2 客户端注入类

| 工具 | 作用 |
|---|---|
| `mkstubs.py` | 用 lupa 自带 LuaJIT 把 Lua 源码编译成字节码并写进 `Win\lua` 树。**这一步验证了最关键的能力：我们能给游戏注入自己的 Lua 模块**，之后就不必改 C# |
| `inject_*.py` | 各模块的注入/还原脚本，见 [05](05_客户端Lua覆盖清单.md) |
| `revert_lua.py` | 把注入的 Lua 改动全部还原（当初用于定位 `CheckEnv_Illegal_modification` 的触发源） |
| `inject_cfgdump.py` | 运行时 dump 配置表（`cfg\*.txt` 的来源） |

## 6.5 IL2CPP 静态分析

- `tools\Il2CppDumper\` —— 现成工具
- `il2cpp_out\dump.cs` —— **21 MB**，全部 C# 类型与 RVA
- `il2cpp_out\script.json` —— 方法地址表 + 字符串交叉引用表（`disasm.py` / `xref.py` / `addr.py` 都靠它）

## 6.6 环境依赖

- **Python 3.8.6**
- `lupa`（`lupa.luajit21`）—— 所有注入脚本用它把 Lua 源码编译成 LuaJIT 字节码
- `capstone` —— `disasm.py` / `raw.py`
- `pefile` —— `exports.py` / `cjson_check.py`
- `pyinstaller 3.6` —— 把服务端打包成 exe
