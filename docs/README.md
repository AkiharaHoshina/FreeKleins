## 这套东西干什么

原客户端连不上已关闭的官方服务器。这里用**两个本机假服务端**顶替官方后端，配合**一处二进制补丁**，
让游戏在纯离线状态下跑起来：登录 → 大厅 → 主线/副本 → 编队 → 抽卡 → 升级 → 换装 → 战斗结算。

- `D:\hxls` —— **原始客户端，全程未改动**
- `D:\KleinsPatch` —— 工作副本，补丁与所有试验都在这里

## 怎么启动（三步）

**第 1 步**：启动两个服务端。
双击 `D:\KleinsPatch\启动服务端.bat`（会最小化起两个窗口）。
脚本会**先探测端口**：哪个端口没起就起哪个，已经在跑的直接跳过（不会重复启动），
然后**轮询等待到真正就绪**再打印 `[OK]`。
或者手动分别双击：

| 可执行文件 | 端口 | 作用 |
|---|---|---|
| `D:\KleinsPatch\_re\fakeserver.exe` | **10300/TCP** | HTTP 层：版本更新、公告、账号、实名 |
| `D:\KleinsPatch\_re\bizserver.exe` | **10301/TCP** | 业务层：登录、角色、编队、抽卡、关卡、战斗结算 |

> 不想用 exe 也行：`python D:\KleinsPatch\_re\fakeserver.py` 和 `python D:\KleinsPatch\_re\bizserver.py`。
> 两者行为完全一致，exe 只是把 Python 3.8 运行时打进去了。

**第 2 步**：双击 `D:\KleinsPatch\环行旅舍.exe` 开游戏。

**第 3 步**：进游戏后直接玩。首次登录会正常走完，账号/存档由假服务端接管。

关服务端：双击 `D:\KleinsPatch\停止服务端.bat`，或直接关掉那两个黑窗口。

### 启动顺序 / 排错

- **顺序：先给客户端打补丁 → 再起服务端 → 后起游戏。**
  反了（服务端先开着、拿**没打过补丁**的客户端去连）客户端可能提示**网络问题**，这是**已知问题**；
  补丁用过之后就不用担心了。游戏已经开着才发现服务端没起，重登一次即可。
- **端口被占**：`启动服务端.bat` 已经处理了这种情况——检测到端口在监听就跳过启动，直接用现成的。
  想强制重来就先运行 `停止服务端.bat`。脚本里打印的 `[跳过]` / `[启动]` 就是它实际做的动作。
- **exe 放哪儿都行**？不行。exe 必须待在 `D:\KleinsPatch\_re\`，因为它要就地读同目录的
  `cfg\`（58 张配置表）和 `routes.json`。日志文件也写在这个目录。
- **游戏无反应/卡在登录**：看 `D:\KleinsPatch\_re\bizserver.log`（业务层）和
  `D:\KleinsPatch\_re\probe.log`（HTTP 层），每次请求都有记录。

## 关键文件速查

```
D:\KleinsPatch\
├── 环行旅舍.exe                 ← 游戏本体（已打补丁）
├── 启动服务端.bat / 停止服务端.bat
├── docs\                        ← 本档案
├── Win\lua\                     ← 被覆盖的 Lua（每个都有 *_orig.lua 原件副本）
├── 环行旅舍_Data\
│   └── resources.assets         ← 唯一改过的二进制（PlatfromUrl）
├── _backup_LocalLow\            ← 游戏运行时状态目录的备份
└── _re\                         ← 所有服务端代码、工具、配置、日志
    ├── fakeserver.exe / bizserver.exe   ← 打包好的服务端
    ├── fakeserver.py / bizserver.py     ← 源码
    ├── bizproto.py              ← CSPKG 协议（帧/XXTEA/protobuf）
    ├── playerdata.py            ← 存档 + 各命令响应构造
    ├── cfgdata.py               ← 读取 cfg\ 下配置表
    ├── routes.json              ← HTTP 路由表（热重载，改完即生效）
    ├── player.json              ← 玩家存档
    ├── settings.json            ← 玩家设置
    ├── cfg\                     ← 58 张从运行时 dump 出来的真实配置表
    ├── ljbc.py                  ← ★ LuaJIT 字节码反汇编器
    └── inject_*.py              ← 客户端 Lua 注入/还原脚本
```
